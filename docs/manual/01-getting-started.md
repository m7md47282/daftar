# البدء في استخدام دفتر

## تسجيل الدخول

1. افتح رابط النظام، وأدخل **اسم المستخدم** و**كلمة المرور**، ثم اضغط **دخول**.
2. للخروج اضغط **خروج** أعلى يسار الشاشة ثم أكّد.

## النسخة التجريبية

في صفحة الدخول زرّان لتجربة النظام دون حساب:

- **دخول كمالك**: ترى كل الفروع والتقارير.
- **دخول كمحاسب فرع**: ترى فرع جدة فقط.

تُنشأ لك نسخة خاصة ببيانات وهمية لتاجر أقمشة بثلاثة فروع، وتظهر أعلى الشاشة عبارة "نسخة تجريبية — تُحذف خلال 24 ساعة".
كل ما تُدخله يُحذف تلقائياً. لا يمكن إضافة مستخدمين في النسخة التجريبية.

## الصلاحيات: المالك ومحاسب الفرع

| | المالك | محاسب الفرع |
|---|---|---|
| الفروع | جميع الفروع، ويختار الفرع في كل مستند | فرعه فقط، وحقل الفرع مقفل |
| التقارير | موحّدة لكل الفروع أو لفرع محدد | أرقام فرعه فقط |
| تكلفة الأصناف ومجمل الربح | تظهر | لا تظهر |
| إضافة حسابات وفروع ومستودعات | نعم | عرض فقط |
| إعدادات النظام والمستخدمين | نعم | لا |
| المحاسب الذكي | نعم (بعد تفعيله) | لا |

يظهر دورك بجانب اسمك أعلى الشاشة: "المالك — جميع الفروع" أو "محاسب — اسم الفرع".

## شكل الشاشة

- **الشريط العلوي**: اسم المنشأة، مفتاح وضع العمل **[ النظام | المحاسب الذكي ]** (عند تفعيل المحاسب)، اسمك ودورك، تاريخ اليوم ميلادي وهجري، وزر **خروج**.
- **شريط القوائم**: الملفات، الفواتير، السندات، تقارير المخزون، تقارير المحاسبة، المحاسب الذكي (للمالك)، إعدادات النظام، مساعدة.
  - العنصر الذي بجانبه `‹` يفتح قائمة فرعية عند مرور المؤشر عليه.
  - العنصر المكتوب بجانبه "قريباً" لم يُبنَ بعد، وسيظهر في نفس المكان عند إضافته.
- **التبويبات**: كل شاشة تفتح في تبويب. فتح نفس الشاشة مرة ثانية ينقلك إلى تبويبها بدل فتح نسخة جديدة.
  تُغلق التبويب بزر ✕ أو بالضغط على **Esc** أو بضغطة الزر الأوسط للفأرة. إذا كان فيه مستند غير محفوظ يسألك النظام قبل الإغلاق.
- **شريط الحالة** أسفل الشاشة: تذكير بمفاتيح الوظائف.

## الشاشة الرئيسية (التقرير اليومي)

تبويب **الرئيسية** يعرض:

- مبيعات اليوم وعدد الفواتير، ومبيعات الشهر.
- مجمل ربح اليوم والشهر (للمالك فقط).
- النقدية بالصناديق، والمستحق من العملاء.
- أزرار سريعة: فاتورة مبيعات، سند قبض، سند صرف، فاتورة مشتريات، كشف حساب، أرصدة المخزون.

المالك يرى ملخص جميع الفروع، ومحاسب الفرع يرى ملخص فرعه. لتحديث الأرقام اختر **تقارير المخزون ← التقرير اليومي**.

## مفاتيح الوظائف

تعمل في الشاشة المفتوحة حالياً (مساعدة ← اختصارات لوحة المفاتيح):

| المفتاح | الوظيفة |
|---|---|
| F2 | إضافة: مستند أو سجل جديد |
| F3 | حفظ |
| F4 | تعديل (المستندات المرحّلة لا تُعدّل، ويظهر لك طريقة التصحيح) |
| F5 | بحث عن مستند |
| F6 | حذف السطر الحالي في مستند جديد / إلغاء سند مرحّل |
| F7 | طباعة |
| F9 | الانتقال إلى خانة الباركود |
| F11 | إدراج صنف (في الفواتير) أو حساب (في السندات) |
| F12 | إدراج وحدة صنف (في شاشة الأصناف) |
| Enter | الانتقال إلى الخانة التالية |
| Esc | إغلاق الشاشة |

## إدخال الأرقام

يمكن كتابة الأرقام بالأرقام العربية (٠١٢٣) أو الإنجليزية، ويقبل النظام الفاصلة العشرية `,` أو `.`.

## خصوصية البيانات

- بيانات كل منشأة في قاعدة بيانات مستقلة لا تشاركها أي منشأة أخرى.
- لا يرى بياناتك إلا أنت ومن تمنحه صلاحية، والمحاسب يرى فرعه فقط.
- مشغّل المنصة يدير الاشتراكات فقط، ولا يملك شاشة لفتح بياناتك.
- كل دخول إلى حسابك مسجّل في **إعدادات النظام ← سجل الدخول والخصوصية**.
- المحاسب الذكي متوقف افتراضياً. عند تفعيله تُعالَج البيانات التي تسأل عنها لدى Claude (Anthropic).
