# قيد التطوير

العناصر التالية تظهر في القوائم بعلامة **قريباً**، وعند الضغط عليها تظهر رسالة أنها قيد التطوير. ستُضاف في نفس مكانها.

| العنصر | القائمة | البديل الحالي |
|---|---|---|
| نقاط البيع، مرتجع نقاط بيع | الفواتير | فاتورة مبيعات نقدية مع الباركود (F9) |
| فاتورة عرض أسعار | الفواتير | — |
| فاتورة طلب شراء | الفواتير | — |
| كميات إفتتاحية | الفواتير | فاتورة مشتريات، أو سند قيد للقيمة |
| فاتورة تسوية مخزون | الفواتير | — |
| إدخال كميات الجرد | إعدادات النظام | — |
| القيود التلقائية ... | إعدادات النظام | القيود تُنشأ تلقائياً بقواعد ثابتة (انظر القواعد المحاسبية) |
| تقارير نقاط البيع، عرض الأسعار، الكميات الافتتاحية، تسوية المخزون، التحول بين المستودعات | تقارير المخزون | — |
| الإرسال المباشر عبر واتساب/البريد من النظام | — | زر **إرسال للعميل** يفتح واتساب أو البريد على جهازك برابط الفاتورة |
| الربط مع هيئة الزكاة والضريبة والجمارك (المرحلة الثانية) | — | الفواتير تحمل بيانات الجاهزية ورمز QR للمرحلة الأولى |
