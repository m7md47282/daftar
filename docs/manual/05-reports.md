# التقارير

## عوامل التصفية المشتركة

معظم التقارير فيها:

- **من** و**إلى**: فترة التقرير (أو **حتى تاريخ** للتقارير التراكمية مثل الميزانية).
- **الفرع**: للمالك، جميع الفروع أو فرع محدد. محاسب الفرع يرى فرعه دائماً.

## تقارير المخزون

**قائمة تقارير المخزون**

| التقرير | المسار | ما يعرضه |
|---|---|---|
| دليل الحسابات | تقارير الملفات ← دليل الحسابات | شجرة الحسابات |
| أرصدة المخزون | تقارير الأصناف ← أرصدة المخزون | الكمية لكل صنف ومستودع، الوحدة، متوسط التكلفة، القيمة. خيار "تحت حد الطلب فقط" |
| حركة صنف | تقارير الأصناف ← حركة صنف | كل فاتورة دخل أو خرج فيها الصنف: التاريخ، المستند، الطرف، المستودع، الكمية، السعر، الوارد والصادر |
| أرصدة العملاء | تقارير العملاء ← أرصدة العملاء | المستحق لنا من كل عميل. خيار إخفاء الأرصدة الصفرية، وزر طباعة |
| كشف حساب عميل | تقارير العملاء ← كشف حساب عميل | |
| أرصدة الموردين | تقارير الموردين ← أرصدة الموردين | المستحق علينا لكل مورد |
| كشف حساب مورد | تقارير الموردين ← كشف حساب مورد | |
| التقرير اليومي | التقرير اليومي | يفتح الرئيسية ويحدّث أرقامها |
| تقارير المبيعات / المشتريات ومردوداتها | | قائمة الفواتير في الفترة: الرقم، التاريخ، الطرف، الفرع، الدفع، الصافي، الضريبة، الإجمالي، المتبقي، من أعدّها |

انقر على مستند في التقارير لفتحه في تبويب.

## كشف حساب

**تقارير المحاسبة ← كشف حساب** (أو زر **كشف حساب** من شاشة العميل/المورد/دليل الحسابات)

- اختر الحساب والفترة.
- يعرض **الرصيد الافتتاحي**، ثم كل حركة: التاريخ، المستند، البيان، الفرع، مدين، دائن، **الرصيد** الجاري، ثم الرصيد الختامي.
- إذا اخترت حساباً رئيسياً يشمل الكشف كل الحسابات تحته.
- **دفتر الأستاذ العام** يستخدم نفس الشاشة.

## التقارير المحاسبية

**قائمة تقارير المحاسبة**

| التقرير | ما يعرضه |
|---|---|
| **اليومية العامة** | كل القيود في الفترة: رقم القيد، التاريخ، الحساب، مدين، دائن |
| **تقرير القيمة المضافة** | المبيعات والمشتريات الخاضعة للضريبة، ضريبة المخرجات والمدخلات، وصافي الضريبة المستحقة. الأرقام مطابقة لنموذج إقرار ضريبة القيمة المضافة |
| **ميزان مراجعة** | لكل حساب: رصيد أول المدة، حركة الفترة، الرصيد الختامي (مدين/دائن). خيار "الحسابات الفرعية فقط" |
| **حساب المتاجرة** | المبيعات ناقص المردودات ناقص تكلفة البضاعة المباعة = مجمل الربح |
| **حساب الأرباح والخسائر** | مجمل الربح + إيرادات أخرى − المصروفات = صافي الربح |
| **الميزانية العمومية** | الأصول، الخصوم، حقوق الملكية حتى تاريخ محدد. إذا لم تتوازن تظهر رسالة تحذير |

أوضاع العرض (الخام، قبل التسويات، بعد التسويات…)، ودفتر الأستاذ، وورقة التسويات، وقائمة التغيرات في حقوق الملكية،
والمقارنات، والنسخ المجمدة: انظر [الشاشات المحاسبية الأساسية](11-core-accounting.md)، القسمين 7 و9.

الربط المباشر مع هيئة الزكاة والضريبة والجمارك (فاتورة) غير مفعّل بعد. التقرير يُستخدم لتعبئة الإقرار يدوياً.

## الطباعة

استخدم زر **طباعة** في التقرير، أو طباعة المتصفح (Ctrl+P). أشرطة القوائم والتبويبات لا تظهر في الطباعة.
