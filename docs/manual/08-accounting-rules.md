# القواعد المحاسبية

## الدفتر لا يُعدّل

- كل فاتورة وسند يُرحَّل فوراً عند الحفظ بقيد محاسبي متوازن (المدين = الدائن).
- القيود المرحّلة **لا تُعدّل ولا تُحذف**. التصحيح يكون:
  - للفواتير: **فاتورة مرتجع**.
  - للسندات: **إلغاء السند** (قيد عكسي بتاريخ اليوم).
- لا يُقبل قيد بتاريخ داخل سنة مالية مقفلة.
- القيود على الحسابات الفرعية فقط، وكل حساب مرتبط بفرع لا يُستخدم إلا في فرعه.

## القيود التلقائية للفواتير

| الفاتورة | مدين | دائن |
|---|---|---|
| **مبيعات** | العميل (الصافي شامل الضريبة) | 41 المبيعات (بدون ضريبة)، 2102 ضريبة المخرجات |
| ↳ المدفوع | صندوق الفرع | العميل |
| ↳ التكلفة | 51 تكلفة البضاعة المباعة | 1104 المخزون |
| **مرتجع مبيعات** | 42 مردودات المبيعات، 2102 ضريبة المخرجات | العميل |
| ↳ المدفوع | العميل | صندوق الفرع |
| ↳ التكلفة | 1104 المخزون | 51 تكلفة البضاعة المباعة |
| **مشتريات** | 1104 المخزون (بدون ضريبة)، 1105 ضريبة المدخلات | المورد |
| ↳ المدفوع | المورد | صندوق الفرع |
| **مرتجع مشتريات** | المورد | 1104 المخزون، 1105 ضريبة المدخلات |
| ↳ المدفوع | صندوق الفرع | المورد |

حتى الفاتورة النقدية تمر بحساب الطرف (عميل عام مثلاً)، فيظهر البيع والتحصيل كلاهما في كشف حسابه.
مركز التكلفة المختار يُسجَّل على أسطر المبيعات والمردودات والتكلفة.

## القيود التلقائية للسندات

| السند | مدين | دائن |
|---|---|---|
| سند قبض | الصندوق/البنك (الطرف المدين) | حسابات الجدول |
| سند صرف | حسابات الجدول | الصندوق/البنك (الطرف الدائن) |
| سند قيد | كما أُدخل | كما أُدخل |
| إلغاء سند | عكس القيد الأصلي بتاريخ اليوم | |

## تكلفة المخزون: المتوسط المرجّح المتحرك

- الكميات تُحفظ بالوحدة الأساسية للصنف (مثل المتر). الرول = 50 متر يُخصم 50 متراً.
- **المشتريات** تضيف الكمية بقيمتها الصافية (بدون ضريبة)، فيتغير متوسط التكلفة.
- **المبيعات** تُخرج الكمية بمتوسط التكلفة الحالي، وتُسجَّل كتكلفة بضاعة مباعة.
- **مرتجع المبيعات** يعيد البضاعة بنفس التكلفة التي خرجت بها في الفاتورة الأصلية.
- **مرتجع المشتريات** يُخرج البضاعة بقيمتها في المرتجع.
- الكمية المجانية تدخل في حركة المخزون والتكلفة، لا في المبلغ.
- إذا وصلت كمية الصنف إلى صفر تُصفَّر قيمته أيضاً.

## الحساب والتقريب

- المبالغ تُحفظ بالهللة، والكميات بثلاث خانات عشرية.
- لكل سطر: الإجمالي = الكمية × السعر ← خصم السطر ← خصم الفاتورة ← الضريبة على الصافي حسب نسبة الصنف.

## الفوترة الإلكترونية (هيئة الزكاة والضريبة والجمارك)

فواتير المبيعات ومرتجعاتها جاهزة للمرحلة الثانية، لكنها **غير مربوطة بالهيئة بعد**:

- لكل فاتورة معرّف فريد (UUID)، وعدّاد فواتير متسلسل، وسلسلة hash تربطها بالفاتورة السابقة.
- رمز QR (المرحلة الأولى): اسم البائع، الرقم الضريبي، الوقت، الإجمالي، الضريبة.
- النوع: **فاتورة ضريبية** إذا كان للعميل رقم ضريبي، وإلا **فاتورة ضريبية مبسطة**.
- هذا سبب منع تعديل الفواتير أو حذفها: أي تغيير يكسر التسلسل الضريبي.
