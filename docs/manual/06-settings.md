# إعدادات النظام

كل إعدادات هذه القائمة للمالك فقط، عدا عرض **السنوات المالية**.

## بيانات المنشأة والطباعة

**إعدادات النظام ← إعدادات ...** (وكذلك عناصر "إعدادات طباعة الفواتير/سند صرف/سند قبض")

**بيانات المنشأة (تظهر على الفواتير):** اسم المنشأة، الاسم بالإنجليزي، **الرقم الضريبي**، السجل التجاري، العنوان، الهاتف.

**إعدادات الطباعة:**

- **حجم الورق**: A4 أو إيصال حراري 80 مم.
- **تذييل الفاتورة**: نص يظهر أسفل كل فاتورة.
- **السماح بالبيع بكمية أكبر من المتوفر في المستودع**: عند إيقافه (الافتراضي) يرفض النظام أي فاتورة تُخرج كمية أكبر من رصيد المستودع.

> أدخل الرقم الضريبي للمنشأة قبل إصدار الفواتير، فهو يدخل في رمز QR الضريبي.

## المستخدمون، السنوات المالية، والسجل

هذه الأقسام تغيّرت. التعليمات الحالية في [الشاشات المحاسبية الأساسية](11-core-accounting.md):

- **إعدادات النظام ← المستخدمون والدعوات**: دعوة الموظفين بالرابط، والمقاعد، والإيقاف. انظر القسم 11.
- **إعدادات النظام ← السنوات والفترات**: فتح السنة، وقفل الأشهر وإعادة فتحها. انظر القسم 4.
- **إعدادات النظام ← إقفال السنة المالية**: الإقفال التمهيدي والنهائي والتكميلي. انظر القسم 10.
- **إعدادات النظام ← سجل الدخول والإجراءات**. انظر القسم 12.

## المحاسب الذكي

**إعدادات النظام ← المحاسب الذكي ...**: التفعيل، طريقة العمل الافتراضية، الرصيد وسجل استخدامه. التفاصيل في [07-ai-assistant.md](07-ai-assistant.md).
