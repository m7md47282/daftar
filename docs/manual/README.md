# دليل المستخدم — دفتر

دفتر نظام محاسبي سحابي للتجار في السعودية (تجار الأقمشة أولاً). يحتفظ بنفس القوائم والشاشات ومفاتيح الوظائف
التي يعرفها المستخدم من النظام المكتبي، ومعه **محاسب ذكي** يعمل داخل صلاحيات النظام فقط.

## اصطلاحات هذا الدليل

- مسار القائمة يُكتب هكذا: **الفواتير ← فاتورة مبيعات**.
- **المالك** (مدير الشركة) يرى جميع الفروع. **محاسب الفرع** (موظف محدد بفرع) يرى فرعه فقط. ما يخص المالك وحده مذكور صراحةً.
- المبالغ بالريال السعودي. أسعار الأصناف **بدون** ضريبة القيمة المضافة (15%) ما لم يُذكر غير ذلك.

## ملاحظة لمن يستخدم هذا الدليل آلياً (المحاسب الذكي)

كل ملف يبدأ بترويسة فيها `id` و`title` و`keywords`، وكل عنوان من المستوى الثاني (`##`) قسم مستقل يمكن اقتطاعه
وحده. أسماء الشاشات والحقول والأزرار مكتوبة **حرفياً** كما تظهر في النظام لكي يطابقها المستخدم بسهولة.
عند الإجابة استشهد بمسار القائمة واسم الحقل، ولا تَعِد بشيء مذكور في `coming-soon`.
