# الملفات الأساسية (قائمة الملفات)

## دليل الحسابات

**الملفات ← دليل الحسابات**

شجرة الحسابات بأرقامها وأسمائها ونوعها (أصول، خصوم، حقوق ملكية، إيرادات، مصروفات).

- الحساب **الرئيسي** (مجموعة) يجمع حسابات تحته ولا يُرحَّل عليه مباشرة. الحساب **الفرعي** هو الذي تُسجَّل عليه القيود.
- اضغط ▾ / ◂ لطيّ المجموعة أو فتحها. حسابات العملاء والموردين تبدأ مطويّة لأنها طويلة.
- ابحث بالرقم أو الاسم من خانة البحث.
- **كشف حساب**: زر بجانب كل حساب فرعي، أو انقر عليه نقراً مزدوجاً.

**إضافة حساب (للمالك):** اختر حساباً رئيسياً، واكتب اسم الحساب الفرعي الجديد، ثم اضغط **إضافة تحت ...**. يُعطى الرقم تلقائياً.

- لا يمكن إضافة حساب تحت حساب فرعي.
- حسابات العملاء والموردين لا تُضاف من هنا. تُنشأ تلقائياً عند إضافة عميل أو مورد.

## الأصناف

**الملفات ← الأصناف**

يسار الشاشة قائمة الأصناف مع الكمية، وفيها بحث بالاسم أو الرقم أو الباركود. انقر على صنف لفتحه.

### إضافة صنف

1. اضغط **إضافة (F2)**.
2. **رقم الصنف**: اتركه فارغاً ليُعطى تلقائياً، أو اكتب رقمك. لا يتغير بعد الحفظ.
3. **التصنيف**: اختر من السابق أو اكتب تصنيفاً جديداً.
4. **وصف عربي** (إلزامي) و**وصف إنجليزي** (اختياري).
5. **نسبة الضريبة %**: الافتراضي 15.
6. **حد الطلب**: إذا نزلت الكمية تحته يظهر الصنف بعلامة "تحت حد الطلب" في تقرير أرصدة المخزون.
7. جدول **الوحدات**:
   - **الوحدة الأولى هي الأساسية** (مثل المتر) وعبوتها 1 دائماً. كل الكميات في المخزون تُحسب بها.
   - كل وحدة أخرى: **العبوة** = عدد الوحدات الأساسية فيها. مثال: الرول = 50 متر.
   - **الباركود** و**سعر البيع** لكل وحدة. سعر البيع بدون ضريبة.
   - **الوحدة الافتراضية**: تُختار تلقائياً عند إدخال الصنف في الفاتورة. وحدة افتراضية واحدة فقط.
   - **إدراج وحدة صنف (F12)** لإضافة وحدة.
8. اضغط **حفظ (F3)**.

لكل صنف لوحة **الكمية الحالية** في كل مستودع وإجماليها، ومتوسط التكلفة (للمالك).

## العملاء والموردين

**الملفات ← العملاء** أو **الملفات ← الموردين**

| الحقل | ملاحظة |
|---|---|
| رقم الحساب | تلقائي: حساب فرعي تحت 1103 العملاء أو 2101 الموردون |
| الاسم | إلزامي |
| الجوال، البريد الإلكتروني، العنوان | اختيارية، وتظهر على الفاتورة |
| الرقم الضريبي | 15 رقماً يبدأ وينتهي بـ 3 |
| الفرع | للمالك عند الإضافة: "مشترك بين جميع الفروع" أو فرع محدد |

- القائمة يساراً تعرض الحساب والاسم والرصيد، مع بحث بالاسم أو الجوال.
- عند فتح عميل أو مورد يظهر **الرصيد** وزر **كشف حساب**.
- رصيد العميل الموجب = مستحق لنا. رصيد المورد = مستحق علينا.
- يوجد عميل باسم **عميل عام** يُستخدم افتراضياً في فواتير المبيعات النقدية.

## الفروع والمستودعات ومراكز التكلفة

**الملفات ← الفروع والمستودعات ومراكز التكلفة**

أربع قوائم: **الفروع**، **المستودعات** (لكل مستودع فرع)، **مراكز التكلفة**، **المناديب** (لكل مندوب فرع).

- الإضافة للمالك فقط. محاسب الفرع يرى الشاشة للعرض.
- عند إضافة فرع جديد يُنشأ له تلقائياً **مستودع** و**صندوق نقدية** (حساب تحت 1101).
- مركز التكلفة اختياري في الفواتير والسندات، ويُستخدم لتحليل الإيرادات والمصروفات.
