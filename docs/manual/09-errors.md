# رسائل النظام وحلولها

النص بين علامات التنصيص هو نص الرسالة كما يظهر (`…` = جزء متغير).

## الفواتير

| الرسالة | السبب | الحل |
|---|---|---|
| "اختر العميل" / "اختر المورد" | لم يُحدَّد الطرف | اختر من حقل العميل/المورد |
| "أدخل صنفاً واحداً على الأقل" | لا يوجد صنف في الجدول | أضف صنفاً |
| "أدخل الكمية للصنف …" | سطر بلا كمية | أدخل الكمية أو احذف السطر |
| "حدد سعر الصنف …" | السعر صفر أو فارغ | أدخل السعر، أو حدد سعر بيع للوحدة في شاشة الأصناف |
| "الكمية غير كافية من …: المتاح … والمطلوب …" | رصيد المستودع أقل من المطلوب | اختر مستودعاً آخر، أو أدخل فاتورة مشتريات أولاً، أو يفعّل المالك البيع بالسالب |
| "الفاتورة النقدية يجب أن تُدفع بالكامل، أو اختر طريقة الدفع آجل" | المدفوع أقل من الصافي في فاتورة نقدية | اختر **آجل** وأدخل المدفوع |
| "المدفوع (…) أكبر من صافي الفاتورة (…)" | المدفوع زائد | صحّح المدفوع |
| "مرتجع المبيعات يحتاج رقم الفاتورة الأساسية" | لم يُدخل رقم الفاتورة الأصلية | اكتب الرقم واضغط **جلب الأصناف** |
| "الفاتورة الأساسية رقم … غير موجودة" | رقم خاطئ | ابحث عن الفاتورة في تقارير المبيعات |
| "الفاتورة الأساسية تخص طرفاً آخر / فرعاً آخر" | عدم تطابق | استخدم نفس العميل والفرع |
| "الكمية المرتجعة من … أكبر من المتبقي في الفاتورة الأساسية" | إرجاع أكثر من المباع (مع المرتجعات السابقة) | قلّل الكمية |
| "الصنف … غير موجود في الفاتورة الأساسية" | صنف أو وحدة لم تُبَع في الأصلية | احذف السطر |
| "الصنف … موقوف" | الصنف غير فعّال | استخدم صنفاً آخر |
| "الوحدة "…" غير معرفة للصنف …" | وحدة غير موجودة | اختر من الوحدات المعروضة |
| "المستودع لا يتبع هذا الفرع" | مستودع فرع آخر | اختر مستودع فرع الفاتورة |
| "لا يوجد مستودع لهذا الفرع" / "لا يوجد صندوق نقدية لهذا الفرع" | نقص في إعداد الفرع | يضيفه المالك من الفروع والمستودعات |
| "الفاتورة المرحّلة لا تُعدّل…" / "الفواتير المرحّلة لا تُحذف…" | قاعدة النظام | أنشئ فاتورة مرتجع |

## السندات

| الرسالة | السبب | الحل |
|---|---|---|
| "أدخل حساباً واحداً على الأقل" | الجدول فارغ | أضف حساباً |
| "السند غير متوازن: المدين … والدائن …" | سند قيد غير متوازن | ساوِ المجموعين |
| "السطر …: أدخل مبلغاً في المدين أو الدائن (وليس كليهما)" | | مبلغ في جهة واحدة لكل سطر |
| "السطر …: أدخل المبلغ" | سطر بلا مبلغ | أدخل المبلغ أو احذف السطر |
| "أدخل رقم الشيك" | اخترت شيك بلا رقم | أدخل رقم الشيك |
| "لا يمكن أن يكون الطرف النقدي هو نفس حساب السطر" | نفس الحساب في الجهتين | اختر حساباً آخر |
| "لا يمكن ترحيل قيد بمبلغ صفر" | المجموع صفر | أدخل المبالغ |
| "السند ملغى مسبقاً" | | لا حاجة لإجراء |
| "السند المرحّل لا يُعدّل…" | قاعدة النظام | ألغِه (F6) ثم أنشئ سنداً صحيحاً |

## الحسابات والملفات

| الرسالة | السبب | الحل |
|---|---|---|
| "الحساب … حساب رئيسي ولا يقبل الترحيل، اختر حساباً فرعياً" | اخترت مجموعة | اختر حساباً تحتها |
| "الحساب … يخص فرعاً آخر" | حساب مرتبط بفرع آخر (مثل صندوقه) | اختر حساب فرعك |
| "لا يمكن إضافة حساب تحت حساب فرعي" | | اختر حساباً رئيسياً |
| "حسابات العملاء والموردين تُنشأ من شاشة العملاء/الموردين" | | استخدم **الملفات ← العملاء/الموردين** |
| "الرقم الضريبي يجب أن يكون 15 رقماً يبدأ وينتهي بـ 3" | صيغة خاطئة | صحّح الرقم |
| "رقم الصنف … مستخدم" | رقم مكرر | اختر رقماً آخر أو اتركه تلقائياً |
| "أدخل العبوة لكل وحدة" / "وحدة افتراضية واحدة فقط" | خطأ في جدول الوحدات | صحّح الجدول |

## الصلاحيات والفترات

| الرسالة | السبب | الحل |
|---|---|---|
| "السنة المالية للتاريخ … مقفلة" | التاريخ داخل سنة مقفلة | غيّر التاريخ. الإقفال لا يُلغى |
| "السنة المالية تتداخل مع سنة موجودة" | | تحقق من السنوات المفتوحة |
| "لا تملك صلاحية على هذا الفرع" | محاسب يحاول العمل على فرع آخر | يتولاه المالك أو محاسب ذلك الفرع |
| "هذه العملية متاحة للمالك فقط" / "غير مصرح لك بهذه العملية" | صلاحية المالك | اطلب من المالك |
| "سجّل الدخول أولاً" | انتهت الجلسة | سجّل الدخول من جديد |
| "لا يمكن إضافة مستخدمين في النسخة التجريبية" | | — |

## المحاسب الذكي

| الرسالة | السبب | الحل |
|---|---|---|
| "المحاسب الذكي غير مفعّل لحسابك — فعّله من الإعدادات" | | **إعدادات النظام ← المحاسب الذكي** |
| "رصيد المحاسب الذكي منتهٍ — تواصل مع إدارة المنصة لشحن الرصيد" | الرصيد صفر أو أقل | اطلب الشحن من إدارة المنصة |
| "المحاسب الذكي غير مفعّل على المنصة بعد…" | لم يُضبط مفتاح المنصة | تواصل مع الدعم |
| "رمز التأكيد غير صالح أو منتهي — أعد المعاينة" | مرّت 15 دقيقة أو استُخدم الرمز | اطلب العملية من جديد |
| "البيانات تغيرت بعد المعاينة — أعد المعاينة واطلب التأكيد من جديد" | التأكيد لبيانات مختلفة | معاينة جديدة |
